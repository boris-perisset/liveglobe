# Schriften

`Nohemi` (Pangram Pangram Foundry) in vier Schnitten: Light 300, Regular 400,
Medium 500, SemiBold 600 — als woff2 aus dem `Web-TT`-Paket.

Eingebunden über `@font-face` in `src/styles.css`. Vite hasht und bündelt die
Dateien beim Build, deshalb liegen sie unter `src/` und nicht unter `public/`.

**Lizenz:** Nohemi ist lizenziert (Pangram Pangram Foundry). Die EULA liegt im
Schriftpaket unter `Nohemi/License/EULA.pdf` — ausserhalb des Repos, im
Projektordner. Beim Weitergeben des Repos die Schriftdateien nicht mit
weiterlizenzieren.
